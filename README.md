# Moosa Shahzain — Personal Portfolio

My personal portfolio website. Live at **https://moosashahzain.github.io/**

A multi-page site (HTML + CSS + vanilla JS, no build step):

- `index.html` — Home: hero with 3D-tilt photo, typewriter tagline, highlights, featured video
- `about.html` — About me + education
- `skills.html` — Skills & learning journey
- `projects.html` — Projects & experiments
- `certificates.html` — Courses & certificates
- `business.html` — Digital business & SMM platforms
- `transformation.html` — My transformation: interactive before/after photo slider
- `vision.html` — Achievements + future goals
- `contact.html` — Contact (email, WhatsApp, socials + honest contact form)

Features: light/dark mode, page-wipe transitions between pages, animated canvas
background, scroll reveals, magnetic buttons, card spotlight hover, before/after
drag slider, interface sounds (off by default), mobile-first responsive design,
reduced-motion support.

Photos are embedded directly in the HTML as data URIs (keeps the site fully
self-contained). To swap a photo, ask Muse — or replace the `src="data:image…"`
value in the relevant page.

To preview locally, open `index.html` in a browser.
