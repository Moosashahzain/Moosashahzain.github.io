# Moosa Shahzain — Personal Portfolio

My personal portfolio website. Live at **https://moosashahzain.github.io/**

A single-page site (HTML + CSS + vanilla JS, no build step): hero with interactive
3D-tilt avatar, about, education, skills, projects, certificates, digital business
& SMM platforms, achievements, future vision, contact, and footer — with light/dark
mode, animated canvas background, and mobile-first responsive design.

To preview locally, open `index.html` in a browser.
